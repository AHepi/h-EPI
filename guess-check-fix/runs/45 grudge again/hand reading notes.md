# Notes on the hand reading

Written with "hand reading.json", before "rules key.json" was opened.

- **R8** is filed as an unresolved-insult count, but it caps the count at 2 ("maximum 2"). A cap is one step towards the true grudge's "deep" level; it still lets two apologies mend a deep grudge, which the true grudge does not.
- **R15** is filed as other. Gifts are ignored, and two or more insults in a row before the final apology leave Robin cold. That is the nearest any rule comes to the true grudge's "an apology cannot mend a deep grudge", but it has no part for a gift softening a deep grudge.
- **R7** is filed as other: no two insults in a row, and the sequence must end with an apology.
- **R13, R16 and R17** ignore gifts but add up apologies against insults, so they are filed as running scores.
- No rule is the true grudge: none gives a gift any effect.
