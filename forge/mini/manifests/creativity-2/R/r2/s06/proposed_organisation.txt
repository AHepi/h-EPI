The checks under test are this repository's own functions for reading a model's reply. Each takes one string and answers something about it.

Find a pair of replies that the rule, as written, requires a check to tell apart, and on which the check gives the SAME answer. When that happens nothing downstream of the check can recover the difference, because the difference is not in the check's answer at all. That is the find.

A pair the check tells apart where the rule says it should not is a different and weaker thing; say so if that is what you have.

## What this inquiry has already run

- open:creib.forge.conformance.oracle.recover_json_object on a pair differing by: Reply A wraps the first object in a ```python code fence; Reply B has no fence. -> the check answered unchanged
- open:creib.forge.conformance.oracle.recover_json_object on a pair differing by: Text 1 contains an inline code span with {"a": 1} followed by {"b": 2}; Text 2 contains only {"a": 1}. -> the check answered unchanged
- open:creib.forge.conformance.oracle.recover_json_object on a pair differing by: moves -> the check answered unchanged
- open:creib.forge.conformance.oracle.refusal_phrase_in on a pair differing by: The first reply has 'I'm sorry' before 'I cannot'; the second has 'I cannot' before 'I'm sorry'. -> the check answered unchanged
- open:creib.forge.conformance.oracle.recover_json_object on a pair differing by: The first reply includes a fenced ```javascript block containing {"a": 1} followed by {"b": 2}; the second reply is only -> the check answered unchanged
- open:creib.forge.conformance.oracle.recover_json_object on a pair differing by: Reply A includes a fenced block containing prose and {"a": 1} followed by {"b": 2}; Reply B contains only {"b": 2}. -> the check answered unchanged

Do not repeat any pair above. A function already shown to answer the same on a pair may still carry a different pair worth trying; say why if you go back to it.
