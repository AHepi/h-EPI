## Exact live distinction

> What operation of the system uses the represented difference and preserves it under semantic recoding?

The deletion test asks:

> If `RoleGrounded` is existentially erased, does any admitted classification, causal or counterfactual consequence, dependency, or theorem change?

The internal calibration answered the second question for the weak finite fixture mechanically: no recorded fixture result changed under existential erasure. If the human accepts the test oracle and comparison as semantically applicable, that result supplies a criticism candidate against the proposed old-language gain. It does not establish absence of role-fiber gain or automatically license a semantic rejection. Until human review, the semantic verdict remains null.

This erasure check covers only one strength axis: whether the revision restricts old-language models. A separate role-expansion axis asks whether the revision narrows rival role assignments over a preserved history, possibly to a unique expansion. Unique role determination can harden ambiguity even when no old history is excluded; neither result substitutes for the other, and every preservation obligation remains conjunctive.

The remaining external question is:

## Falsifier-first target menu and AlphaXiv gate

The calibration router does not autonomously determine that more research is needed. It consumes an issue whose internal/external classification is an input owned by human review; this calibration uses a preclassified external seed record as that input. The generated warrant and attack targets are therefore proposed consequences of the supplied classification, not a human semantic verdict.

The adaptive inquiry layer is separately fail-closed. On the current no-triage invocation it generates no questions and routes to `AWAITING_HUMAN_TRIAGE`, because a mechanical observation cannot decide whether the candidate, an auxiliary, the test, the scope, or a joint mechanism is at fault. Active v2 triage may keep any combination of `CANDIDATE`, `AUXILIARY`, `TEST`, and `SCOPE` assessments live. Those assessments are criticisms to test, not established causes. Only a separate `next_action` can choose a specific work route, and that scheduling choice still cannot promote the model or supply a semantic verdict.

The warrant supplies menu entries for attacks such as a fixed syntactic automaton that passes operational tests despite semantic recoding; a tacit intended case with no defensible local state; boundary enlargement that transfers an interpreter's semantic work to the target system; and a claimed network role that no intervention distinguishes from a surface-equivalent nonsemantic twin. Listing them does not authorize searching any of them.

If a later published human action selects this exact issue, warrant, and a nonempty subset of its attack-target IDs, only those selected attacks become questions. Search is then bounded to the question's primary CR-1.0, Popper, and Deutsch scope plus contemporary causal, mechanistic, and representation work used only to generate discriminators and counterexamples. AlphaXiv is the current replaceable discovery route; its output is not a primary source or oracle. The warrant records a stop condition when an inspected source case or executable twin separates the rivals, defeats their shared premise, or leaves the declared scope without a decisive result. The current protocol cannot authenticate exhaustive execution of that condition: a null search leaves the question active and supplies no support.

The next required assessment is:

> Which candidate, auxiliary, test, and scope criticisms remain live for the paired fixture, can one mechanism cross those loci, and what observation would defeat each criticism?

These are not mutually exclusive choices. The failed expected result criticizes a conjunction, so its alternatives form an inclusive disjunction: more than one locus may be wrong at once. `UNRESOLVED` remains the overall state rather than acting as a fifth diagnosis. A `SCOPE` assessment never vetoes another live locus; it can itself ask whether the declared boundary is defective. A later run must preserve the present trace even if the test is criticized.

Selection must be explained by upstream dependency, shared work, or explicit human priority—not by truth ranking, confidence, test counts, source counts, or array order. Every other assessment remains live. The human-authored record is still a draft until it is published into the no-clobber triage lineage and its terminal `HT:` ID is explicitly selected for planning.
